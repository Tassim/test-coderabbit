# Test CodeRabbit

A simple project to experiment with CodeRabbit.

## Getting Started

1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/test-coderabbit.git
    ```
2. Install dependencies:
    ```bash
    npm install
    ```
3. Run the project:
    ```bash
    npm start
    ```

## Project Structure

- `src/` — Source code
- `README.md` — Project documentation
